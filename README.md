# Base CNC

A base command and control (CNC / C2) framework using Telnet to control applications and host a virtualised server. This is particularly useful for CLI tools, automation, bots, plugins, and API calling frameworks.

## Features

The package is planned to have the following features and will be on a slow roll basis with each update planned to include one of the features from the list from below:

- Command registration
- Command registration
- Command parsing
- Session management
- Customised logging
- Middleware/hooks + custom API calling
- Plugin support

The ordering is likely to be followed but task prioritisation based on community request and personal interest will be completed first.

I also plan on incorporating more modern SSH access mode additional to Telnet.
